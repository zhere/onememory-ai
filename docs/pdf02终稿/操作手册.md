# OneMemory记忆管理系统操作手册

## 📖 背景介绍

OneMemory是一个企业级AI记忆管理系统，专为构建具备长期记忆能力的智能应用而设计。系统通过RAG（检索增强生成）技术、知识图谱和智能记忆管理，为AI应用提供完整的上下文理解和知识管理能力。

### 🎯 系统能为您做什么？
- **智能记忆管理**：基于RAG技术的上下文记忆，自动保存和检索相关历史信息
- **知识图谱构建**：自动构建和管理实体关系网络，支持时序实体和关系推理
- **多源数据融合**：整合数据库、文件、网页等多种数据源，提供统一的知识检索
- **Token优化管理**：智能分段和Token使用优化，降低企业AI应用成本
- **企业级管理**：支持多项目、多用户、权限控制等企业级功能
- **可视化分析**：提供知识图谱可视化、数据分析和使用统计

### 👥 目标用户
- **企业AI开发团队**：需要构建具备知识记忆能力的智能客服、数据分析、决策支持系统
- **知识管理专员**：负责企业知识库构建、维护和分析的专业人员
- **AI产品经理**：规划和管理企业AI应用产品路线图的产品决策者
- **数据科学家**：需要进行知识发现、关系推理和智能分析的研究人员
- **系统集成商**：为客户提供AI解决方案和技术集成的服务商

## 🚀 快速开始

### 第一步：访问系统
1. 打开浏览器，访问系统地址
2. 进入登录页面，输入您的账号信息
3. 成功登录后，您将看到系统主界面

### 第二步：创建第一个项目
1. 点击左侧菜单栏的"项目管理"
2. 点击右上角的"新建项目"按钮
3. 填写项目信息：
   - 项目名称：为您的项目起一个有意义的名字
   - 项目描述：简单描述项目的用途
   - 选择AI模型：根据需求选择合适的模型

### 第三步：获取API密钥
1. 项目创建成功后，进入"系统设置"
2. 找到"API密钥管理"部分
3. 点击"生成新密钥"按钮
4. 复制并安全保存您的API密钥

### 📊 6. 分段配置（Segmentation Config）

#### 功能概述
分段配置模块用于设置文本分割策略，优化文本内容的分割效果，提高记忆和检索的准确性。

#### 主要功能
- **分割策略**：选择不同的文本分割方法（语义、固定、自适应、混合）
- **参数配置**：设置分割大小、重叠度、语义阈值等参数
- **结构保护**：保持文本结构的完整性
- **效果测试**：实时测试分割策略的效果
- **模型配置**：配置语言和嵌入模型

#### 操作步骤

##### 选择分割策略
1. 点击左侧菜单"分段配置"
2. 在"分割策略"下拉框中选择：
   - **语义分割**：基于语义相似度进行分割
   - **固定长度**：按固定字符数分割
   - **自适应分割**：根据内容自动调整分割点
   - **混合分割**：结合多种策略进行分割

##### 配置分割参数
1. 设置基础参数：
   - **最大分段长度**：设置每个分段的最大字符数（默认1000）
   - **最小分段长度**：设置每个分段的最小字符数（默认100）
   - **重叠长度**：设置相邻分段的重叠字符数（默认50）
2. 设置语义参数：
   - **语义阈值**：设置语义相似度阈值（0.1-1.0）
3. 启用结构保护：
   - **保持句子完整**：优先在句子边界分割
   - **保持段落完整**：优先在段落边界分割

##### 配置自定义分隔符
1. 在"自定义分隔符"区域输入分隔符
2. 使用转义字符（如\\n\\n表示双换行）
3. 支持多个分隔符组合

##### 测试分割效果
1. 在"测试文本"区域输入样例文本
2. 点击"测试分割"按钮
3. 查看分割结果展示
4. 根据结果调整参数

##### 保存配置
1. 点击"保存配置"按钮
2. 确认配置生效
3. 配置将应用于后续的记忆处理

## 🆘 常见问题解答

### Q1：如何重置忘记的密码？
A：在登录页面点击"忘记密码"，按照提示通过邮箱重置密码。

### Q2：API调用返回401错误怎么办？
A：检查API密钥是否正确配置，确认密钥未过期，检查请求头格式。

### Q3：记忆功能似乎没有生效？
A：检查项目配置中记忆功能是否开启，确认记忆策略参数设置合理，查看记忆管理中的数据。

### Q4：如何降低Token使用成本？
A：优化记忆策略减少不必要的记忆保存，调整Token管理配置，使用更高效的模型。

### Q5：系统响应很慢怎么办？
A：检查网络连接状况，查看系统负载情况，优化记忆检索策略，考虑升级硬件配置。
