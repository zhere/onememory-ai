# Onememory API接口说明文档

## 1. 概述

Onememory提供了一套完整的API接口，用于管理和使用智能记忆系统。本文档详细说明了各个API接口的功能、参数、返回值和使用方法。

## 2. 认证与授权

所有API接口都需要进行认证，通过在请求头中添加`Authorization`字段，值为`Bearer <token>`。

## 3. 接口分类

### 3.1 聊天接口

- 增强聊天
- 基础聊天

### 3.2 知识管理接口

- 知识源管理
- 知识检索

### 3.3 记忆管理接口

- 记忆存储
- 记忆检索

### 3.4 配置接口

- 分段配置
- Token配置

### 3.5 任务规划接口

- 任务状态查询
- 任务管理

### 3.6 工具管理接口

- 工具注册
- 工具列表
- 工具执行

## 4. 分段配置API

### 4.1 概述

分段配置API用于管理文本分段策略，支持多模块特定配置和场景预设。

### 4.2 接口列表

| 接口名称 | HTTP方法 | 路径 | 功能描述 |
|----------|----------|------|----------|
| 获取分段配置 | GET | /api/v1/segmentation-config | 获取当前分段配置 |
| 更新分段配置 | PUT | /api/v1/segmentation-config | 更新分段配置 |
| 测试分段效果 | POST | /api/v1/segmentation-config/test | 测试分段效果 |
| 获取模块配置 | GET | /api/v1/segmentation-config/modules/:module | 获取特定模块的分段配置 |
| 更新模块配置 | PUT | /api/v1/segmentation-config/modules/:module | 更新特定模块的分段配置 |
| 获取场景预设 | GET | /api/v1/segmentation-config/scenarios | 获取场景预设 |
| 应用场景预设 | POST | /api/v1/segmentation-config/scenarios/:scenario/apply | 将场景预设应用到指定模块 |

## 6. 错误处理

所有API接口的错误响应格式统一为：

```json
{
  "success": false,
  "message": "错误描述",
  "error": {
    "code": "错误代码",
    "details": "错误详情"
  }

```

常见错误代码：

| 错误代码 | 描述 |
|----------|------|
| 400 | 请求参数错误 |
| 401 | 未授权访问 |
| 403 | 禁止访问 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |
| 501 | 功能未实现 |

## 7. 最佳实践

1. **模块配置优化**：
   - 记忆模块：使用较小的chunkSize（512-1024 tokens），适合对话记忆
   - RAG模块：使用较大的chunkSize（1500-3000 tokens），适合处理长文档
   - 上下文模块：使用较大的chunkSize（2048-4096 tokens），适配LLM上下文窗口
   - Token模块：使用固定分段策略，精确控制Token使用

2. **场景预设应用**：
   - 长文档：应用longDocument预设
   - 短对话：应用shortConversation预设
   - 代码片段：应用codeSnippets预设

3. **测试分段效果**：
   - 在修改配置前，先测试分段效果
   - 对比不同配置的分段结果
   - 关注分段数量、平均Token数和复杂度

4. **配置管理**：
   - 定期备份配置
   - 跟踪配置变更历史
   - 测试配置变更对系统性能的影响
